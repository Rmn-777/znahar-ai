# Знахарь AI — полная инструкция

Личный помощник-коллектор: вы отправляете боту в **Telegram** или **MAX** что угодно
(текст, голосовые, документы, фото, ссылки, пересланные сообщения) — бот сначала
**надёжно сохраняет исходник**, потом предлагает **меню действий** (конспект,
расшифровка, распознавание текста, своя команда), показывает результат, вы правите
его прямо в чате — и по подтверждению заметка ложится в папку входящих Obsidian.
Исходник, ваши мысли и дополнения ИИ в заметке всегда различимы.

Форк [obsidian-telegram-ai](https://github.com/reaLm74/obsidian-telegram-ai).
Версии для ПК и Android — это один и тот же плагин Obsidian.

---

## 1. Установка

### ПК (Windows/macOS/Linux)

1. Откройте папку хранилища (vault) в проводнике.
2. Внутри найдите скрытую папку `.obsidian/plugins/` (если `plugins` нет — создайте;
   предварительно в Obsidian: Настройки → Сторонние плагины → отключить «Ограниченный режим»).
3. Создайте папку `znahar-ai` и положите в неё **три файла** из сборки:
   `main.js`, `manifest.json`, `styles.css`.
4. Перезапустите Obsidian → Настройки → Сторонние плагины → включите **«Знахарь AI»**.

### Android

То же самое: скопируйте три файла в `.obsidian/plugins/znahar-ai/` внутри
синхронизированного хранилища (или на телефоне через любой файловый менеджер) и
включите плагин. Telegram-бот в мобильном Obsidian работает; экономия батареи
приостанавливает приём, пока Obsidian свёрнут (настраивается).

## 2. Каналы: Telegram и MAX — независимые дороги

Оба канала работают **параллельно и независимо**: подключены оба — пишите в любой;
один недоступен — второй продолжает. Блокировка Telegram не влияет на MAX и наоборот.

### Telegram-бот

1. В Telegram: **@BotFather** → `/newbot` → имя → username (заканчивается на `bot`).
2. Скопируйте токен (вида `123456:AAH...`).
3. Настройки плагина → Бот → вставьте токен.
4. **Разрешённые чаты**: впишите свой Telegram username (без @). Если не знаете —
   отправьте боту любое сообщение, он подскажет, что вписать.

### MAX-бот

1. В MAX: мини-приложение **«MAX для бизнеса»** → Чат-боты → создать бота →
   Настройки → **«Получить токен»**.
2. Настройки плагина → Интерактивный режим → **«Канал MAX»** → вкл. → вставьте токен.
3. Перезапустите Obsidian (или нажмите «Перезапустить» в настройках бота).
4. **Разрешённые чаты** для MAX: впишите свой **цифровой user id MAX**. Если не знаете —
   отправьте боту сообщение: в отказе он назовёт ваш id, добавьте его цифрами.
5. Ограничение текущей версии: из MAX принимается **текст и кнопки**; фото/документы/
   голос из MAX пока не скачиваются (используйте для них Telegram). Планируется в
   следующей версии.

> **Главное устройство.** Защита от двойного опроса: назначьте «Главное устройство»
> в настройках бота — только оно слушает ботов. Прочие установки ставятся на паузу.
> Невыполненные сообщения Telegram держит 24 часа и отдаст при подключении.

## 3. ИИ-провайдер

Без ИИ плагин тоже работает: сообщения сразу попадают во входящие как исходники.
С ИИ открывается меню действий. Один провайдер закрывает текст + фото + голос:

| Провайдер | Бесплатно? | Из РФ без VPN | Фото | Голос | Base URL | Примечание |
|---|---|---|---|---|---|---|
| **Google Gemini** (рекомендуется) | да, щедрый лимит | ❌ гео-блок — нужен VPN на машине, где Obsidian | да | да (нативно) | встроено | ключ: [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |
| **VseGPT** (агрегатор, РФ) | стартовый кредит, далее ~копейки | ✅ рубли/СБП | да (Gemini-модели) | нет | `https://api.vsegpt.ru/v1` | один ключ — десятки моделей ([vsegpt.ru](https://vsegpt.ru)) |
| **z.ai (GLM)** | включено в подписку Coding Plan | ✅ | нет (текст) | нет | `https://api.z.ai/api/paas/v4` | если у вас уже подписка ZCode/GLM |
| **SiliconFlow** (Китай, intl) | бесплатные модели + $1 | ✅ | VL-модели (платно) | нет | `https://api.siliconflow.com/v1` | [siliconflow.com](https://www.siliconflow.com) |
| **OpenAI / OpenRouter / Ollama…** | — | по ситуации | — | Whisper у OpenAI | по провайдеру | любой OpenAI-совместимый |

**Настройка:** Настройки → Искусственный интеллект → «Включить обработку ИИ» →
провайдер → «Настроить» → ключ → **«Проверить ключ»**. Для фото включите **Vision**.
**Язык заметок** → «Русский» явно.

Голос (транскрибация) — только у провайдеров с нативной поддержкой: **Gemini** или
OpenAI Whisper. Поэтому «бесплатно + без VPN + голос» одновременно сейчас не даёт
ни один вариант: либо Gemini+VPN, либо текст без голоса через VseGPT/z.ai.

Промпты: у каждого действия свой встроенный промпт; менять не обязательно.
Своя правка — в разделе «Интерактивный режим → Настроить» (карандаш у действия).

## 4. Настройки «Интерактивного режима»

- **Интерактивное меню действий** — вкл/выкл всего режима (выкл = всё сразу во входящие).
- **Папка входящих** — путь **от корня хранилища**, например `00 Входящие`
  (НЕ дисковый путь; вложенность через `/`; папка создаётся сама).
- **Сохранять вложения в хранилище** — вкл: файлы пишутся в vault и вставляются в
  заметку; выкл: только текст/расшифровка, файл остаётся в Telegram.
- **Действия и быстрый набор** — у каждого действия: вкл/выкл, показ на первом экране,
  свой промпт (пусто = встроенный).
- **Канал MAX** — тумблер и токен (см. §2).

## 5. Как пользоваться

Пришлите боту что угодно → придёт меню с распознанным типом:

- **Голосовое** → «Дословная расшифровка», «Чистая расшифровка», «Протокол встречи», «Конспект лекции»;
- **Ссылка** → «Прочитать статью», «Карточка ссылки», «Конспект видео»;
- **Фото** → «Распознать текст (OCR)», «Описать изображение», «Итоги переписки» (скрин чата), «Черновик баг-репорта»;
- **Документ/PDF** → «Выжимка документа», «Извлечь таблицы», «Спросить документ» (задайте вопрос);
- **Текст/пересланное** → «Конспект», «Полный разбор», «Факты и цифры», «Перевести», «Объяснить просто», «Критический разбор»;
- **Ещё…** — полный каталог; **«✏️ Своя команда»** — напишите что угодно своими словами.

После результата:

- **✅** — сохранить заметку (исходник + ИИ);
- **✏️** — править: напишите «сократи вдвое», «замени заголовок», «добавь раздел про X»…
- **«+ ваш текст»** — добавить свою мысль (попадёт в раздел «Мои мысли», не в ИИ-слой);
- **↩️** — сохранить только исходник, без ИИ;
- **«📥 Сохранить как есть»** в меню — сразу в заметку без обработки.

Заметка в Obsidian:

```markdown
> [!SOURCE] Исходник — Telegram, 18.11.2026 13:15
> …расшифровка/текст/цитата страницы…

## Мои мысли
- ваши дополнения

> [!AI] Обработка ИИ — Конспект (gemini/gemini-flash)
> …результат…
```

## 6. Каталог действий

**Универсальные:** Сохранить как есть · Конспект (TL;DR) · Полный разбор · Извлечь
задачи · Факты и цифры · Перевести · Объяснить просто · Критический разбор ·
Оформить в заметку · Своя команда.
**Ссылки:** Прочитать статью · Карточка ссылки · Конспект видео/подкаста.
**Голос/аудио:** Дословная расшифровка · Чистая расшифровка · Протокол встречи ·
Конспект лекции.
**Фото:** Распознать текст · Описать изображение · Итоги переписки · Баг-репорт.
**Документы:** Выжимка · Извлечь таблицы · Спросить документ.

Команды бота: `/status` (состояние), `/retry` (повтор неудавшихся), `/category`
(категории), `/search` (поиск по хранилищу).

## 7. Типовые ошибки

| Симптом | Причина и решение |
|---|---|
| «Провайдер отклонил регион — проверьте VPN…» | Gemini блокирует российские IP. Нужен VPN **режима «весь трафик»** на машине с Obsidian (умные VPN часто пропускают api.googleapis.com напрямую) — либо провайдер без гео (VseGPT/z.ai/SiliconFlow) |
| «ИИ ничего не вернул» | Смотрите предыдущую ошибку или повторите действие; частый случай — гео/лимит |
| «Ключ API неверен» | Перепроверьте ключ и провайдера в настройках |
| Файл больше 20 МБ | Лимит Bot API Telegram; подключите аккаунт Telegram в настройках (desktop) или пришлите частями |
| «Бота опрашивает другой клиент» | Назначьте «Главное устройство» в настройках бота |
| Отказ доступа, просят user id | Добавьте названный id (цифрами) в «Разрешённые чаты» |
| Меню не пришло | Obsidian должен быть запущен на главном устройстве; проверьте «Интерактивное меню» и наличие ключа ИИ |
| Сообщения «до включения ИИ» ушли во входящие без меню | Так и задумано: без ключа режим «сразу во входящие» |

## 8. Для разработчиков

Сборка: `npm install && npm run build` (esbuild, бюджет 3.5 МБ). Тесты:
`npm run test:unit` (vitest; порог покрытия на ключевых модулях). Архитектура и
точки встраивания — `ARCHITECTURE.md` в папке проекта. Каналы: Telegram
(`src/telegram/`) и MAX (`src/max/`) — независимые транспорты над общим ядром
`src/interactive/` (меню → действие → превью → подтверждение) и слоем надёжности
`src/processing/` (ledger, ретраи, ровно-однократная запись).
